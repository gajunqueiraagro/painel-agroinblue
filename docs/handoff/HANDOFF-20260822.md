### NULL × zero
`NULL` = não planejado · `0` = planejado como zero.
Campo vazio grava NULL; campo com zero grava 0; NULL volta como travessão.

**Assimetria declarada:** a distinção existe SÓ no modo individual. No
Global a soma coalescente não distingue "ninguém planejou" de "todos
planejaram zero". Preço de agregar, não defeito.
